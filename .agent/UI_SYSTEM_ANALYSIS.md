### 現有組件清單

#### 1. Streamlit 訓練 UI (`training_system/app.py`)
- **行數**: 2,210 行
- **功能**:
  - 品種選擇 (分類式)
  - 訓練配置
  - 訓練啟動/停止
  - GPU 監控
  - 訓練進度圖表
  - 交易記錄

#### 2. React 前端 (`frontend/src/`)
- **組件**:
  | 組件 | 大小 | 功能 |
  |------|------|------|
  | Dashboard.tsx | 1.5KB | 主布局 |
  | AccountSummary.tsx | 2.1KB | 帳戶摘要 |
  | InteractiveChart.tsx | 2.5KB | K線圖 (Mock數據) |
  | PositionsTable.tsx | 4.6KB | 持倉表 |
  | GlobalControls.tsx | 2.6KB | 全局控制 |
  | GlobalStatus.tsx | 1.2KB | 狀態顯示 |
  | LogStream.tsx | 1.7KB | 日誌流 |

#### 3. FastAPI 後端
- **api/main.py**: 統一API (15.6KB)
- **live_trading_system/api/server.py**: 實盤API (25.3KB)

### 🔴 關鍵問題

| 問題 | 嚴重度 | 說明 |
|------|--------|------|
| **UI分離** | ⭐⭐⭐⭐⭐ | Streamlit和React分離，用戶體驗割裂 |
| **Mock數據** | ⭐⭐⭐⭐ | InteractiveChart使用假數據 |
| **無實時連接** | ⭐⭐⭐⭐ | 前端未連接WebSocket |
| **API重複** | ⭐⭐⭐ | 兩套API (main.py, server.py) |
| **無回測UI** | ⭐⭐⭐ | 缺少回測介面 |
| **無模型管理UI** | ⭐⭐⭐ | 缺少模型倉庫介面 |

### 🟡 次要問題

- 缺少深色/淺色主題切換
- 無移動端適配
- 無多語言支持
- 缺少鍵盤快捷鍵
