## 專案概述

### 專案簡介

OANDA AI 交易機器人是一個基於深度強化學習的智能交易系統，專為 OANDA 外匯平台設計。系統由兩個獨立的核心模組組成：

1. **訓練系統 (Training System)**: 使用強化學習訓練交易模型
2. **實盤交易系統 (Live Trading System)**: 部署訓練好的模型進行實盤交易

### 核心特性

- **多資產交易**: 支援多個交易對同時交易（最多 10 個）
- **強化學習**: 基於 SAC (Soft Actor-Critic) 演算法
- **Transformer 架構**: 使用增強型 Transformer 進行特徵提取
- **風險管理**: 完整的風險控制機制，包括止損、止盈、倉位管理
- **實時監控**: Streamlit 和 FastAPI 雙 UI 系統
- **自動貨幣轉換**: 智能處理不同貨幣對的轉換
- **執行模擬**: 模擬真實市場的延遲和滑點

## 系統架構

### 整體架構圖

```
OANDA Trading Bot
├── Training System (訓練系統)
```

## 運行流程

### 訓練系統運行流程

```
1. 初始化階段
   ├── 載入環境變數 (.env)
   ├── 解析帳戶配置 (AccountProfile)
   ├── 初始化 InstrumentInfoManager
   └── 設定日誌系統

2. 資料準備階段
   ├── 選擇交易對 (trading_symbols)
   ├── 設定時間範圍 (start_time, end_time)
   ├── 下載 OANDA 歷史資料
   ├── 計算所需貨幣轉換對
   ├── 下載貨幣轉換資料
   ├── 建立記憶體映射資料集 (MMAP)
   └── 載入標準化器 (Scalers)

3. 環境初始化
   ├── 建立 UniversalTradingEnvV4
   ├── 設定初始資本
   ├── 配置風險參數
   └── 初始化獎勵系統

4. 模型初始化
   ├── 建立 EnhancedTransformerFeatureExtractor
   ├── 建立 QuantumEnhancedSAC Agent
   └── 載入預訓練模型（如果存在）

5. 訓練循環
   ├── 重置環境
   ├── 獲取觀察 (observation)
   ├── 模型預測動作 (action)
   ├── 環境執行動作
   ├── 計算獎勵 (reward)
   ├── 更新經驗回放緩衝區
   ├── 模型更新（每 N 步）
   ├── 保存檢查點（每 M 步）
   └── 評估模型（每 K 步）

6. 訓練完成
   ├── 保存最終模型
   ├── 生成模型元數據 (.meta.json)
   └── 記錄訓練日誌
```

### 實盤交易系統運行流程

```
1. 系統初始化
   ├── 載入配置 (live_config.json)
   ├── 初始化 OandaClient
   ├── 解析帳戶配置 (AccountProfile)
   ├── 初始化 SystemState
   ├── 初始化 DatabaseManager
   └── 初始化 InstrumentMonitor

2. 模型載入
   ├── 載入預訓練模型 (PredictionService)
   ├── 載入標準化器 (LivePreprocessor)
   └── 驗證模型兼容性

3. 交易循環初始化
   ├── 選擇交易工具 (SystemState)
   ├── 設定目標資本
   ├── 配置風險參數 (RiskManager)
   └── 啟動交易流監聽（可選）

4. 資料緩衝區預熱 (Warmup)
   ├── 對每個選定的工具
   ├── 獲取歷史資料 (lookback_window 長度)
   └── 填充資料緩衝區

5. 主交易循環 (trading_loop)
   ├── 檢查系統狀態 (is_running)
   ├── 執行交易週期 (execute_trade_cycle)
   │   ├── 對每個選定的工具
   │   ├── 獲取最新 K 線資料
   │   ├── 更新資料緩衝區
   │   ├── 特徵工程 (LivePreprocessor)
   │   ├── 模型預測 (PredictionService)
   │   ├── 生成交易信號
   │   └── 處理信號 (OrderManager)
   │       ├── 風險評估 (RiskManager)
   │       ├── 計算倉位大小
   │       ├── 計算止損/止盈
   │       ├── 提交訂單 (OandaClient)
   │       ├── 追蹤訂單狀態
   │       └── 更新倉位 (PositionManager)
   ├── 檢查風險限制
   ├── 更新資料庫記錄
   └── 等待下一個週期 (trading_loop_interval_seconds)

6. 訂單處理流程
   ├── 接收交易信號
   ├── 風險評估
   │   ├── 檢查總暴露限制
   │   ├── 檢查單一工具暴露限制
   │   ├── 計算倉位大小（ATR 或固定點數）
   │   └── 計算止損/止盈價格
   ├── 訂單執行
   │   ├── 建立訂單請求
   │   ├── 設定價格邊界（滑點保護）
   │   ├── 提交到 OANDA API
   │   └── 等待成交確認
   ├── 倉位追蹤
   │   ├── 更新 PositionManager
   │   └── 記錄到資料庫
   └── 監控倉位
       ├── 檢查止損/止盈觸發
       └── 更新未實現損益

7. 風險監控
   ├── 檢查硬止損 (hard_stop_loss_percent)
   ├── 檢查追蹤止損 (trailing_stop_loss_percent)
   ├── 檢查每日虧損限制 (daily_loss_limit_pct)
   └── 觸發緊急停止（如需要）

8. 系統關閉
   ├── 停止交易循環
   ├── 平倉所有開放倉位（可選）
   ├── 關閉資料庫連接
   └── 保存系統狀態
```

## UI 設計

### 訓練系統 UI (Streamlit)

**檔案位置**: `src/oanda_trading_bot/training_system/app.py`

#### 主要功能區塊

1. **系統狀態顯示**
   - 訓練狀態指示器（運行中/停止/完成）
   - 模型總步數（累積里程）
   - 當前會話步數
   - 最新獎勵值
   - 投資組合價值
   - Transformer L2 範數
   - 梯度範數

2. **訓練配置面板**
   - 交易對選擇（分類顯示）
     - Major Pairs（主要貨幣對）
     - Minor Pairs（次要貨幣對）
     - Precious Metals（貴金屬）
     - Indices（指數）
     - Energy（能源）
     - Commodities（商品）
     - Crypto（加密貨幣）
     - Bonds（債券）
   - 時間範圍設定
     - 開始日期
     - 結束日期
     - 資料天數
   - 訓練參數
     - 總訓練步數 (total_timesteps)
     - 保存頻率 (save_freq)
     - 評估頻率 (eval_freq)
     - 風險百分比
     - ATR 止損倍數
     - 最大倉位百分比
     - ATR 週期

3. **資料下載面板**
   - 資料下載進度
   - 貨幣轉換對檢測
   - 下載狀態顯示

4. **實時圖表**
   - 投資組合價值曲線
   - 獎勵曲線
   - 每工具損益分佈
   - 交易次數統計

5. **系統監控**
   - CPU 使用率
   - 記憶體使用率
   - GPU 使用率（如果可用）
   - 磁碟使用率

6. **訓練日誌**
   - 最近交易記錄
   - 訓練指標歷史
   - 錯誤訊息

#### UI 更新機制

- **快速更新區塊** (`@st.fragment(run_every=2)`): 每 2 秒更新關鍵指標
- **慢速更新區塊** (`@st.fragment(run_every=10)`): 每 10 秒更新系統資源
- **共享資料管理器**: 使用 `SharedTrainingDataManager` 在訓練線程和 UI 線程間共享資料

## API 規格

### OANDA API 整合

系統使用 `oandapyV20` 庫與 OANDA V20 REST API 通信。

#### OandaClient 主要方法

1. **`get_account_summary()`**: 獲取帳戶摘要
   - 返回: 帳戶資訊字典，包含餘額、權益、未實現損益等

2. **`get_candles()`**: 獲取 K 線資料
   - 參數: instrument, count, granularity, price
   - 返回: K 線資料列表

3. **`get_bid_ask_candles_combined()`**: 獲取合併的買賣價 K 線
   - 參數: instrument, count, granularity
   - 返回: 合併的買賣價資料列表

4. **`create_order()`**: 建立市價單
   - 參數: instrument, units, stop_loss_on_fill, take_profit_on_fill
   - 返回: 訂單響應字典

5. **`create_order_v2()`**: 建立市價單（增強版）
   - 額外支援: price_bound, client_extensions, time_in_force
   - 返回: 訂單響應字典

6. **`get_open_positions()`**: 獲取開放倉位
   - 返回: 倉位資訊字典

7. **`close_position()`**: 平倉
   - 參數: instrument, long_units, short_units
   - 返回: 平倉響應字典

8. **`get_account_changes()`**: 獲取帳戶變動
   - 使用 last_transaction_id 追蹤變動
   - 返回: 帳戶變動資訊

#### API 錯誤處理

- 使用 `tenacity` 庫實現重試機制
- 預設重試 3 次，間隔 2 秒
- 僅對 `V20Error` 異常重試

## 模型架構

### Enhanced Transformer Feature Extractor

#### 架構組成

1. **符號嵌入層 (Symbol Embedding)**
   - 輸入: 符號 ID (0 到 num_symbols-1)
   - 輸出: 符號嵌入向量
   - 支援填充符號 (padding_idx = num_symbols)

2. **多尺度特徵提取 (MSFE)**
   - 使用多個時間尺度卷積
   - 預設尺度: [3, 5, 7, 11]
   - 融合多尺度特徵

3. **Transformer 編碼器**
   - 層數: 24 層（可配置）
   - 注意力頭數: 16（可配置）
   - 隱藏維度: 1024（可配置）
   - 中間層維度: 4096（可配置）
   - 支援自適應注意力機制

4. **跨時間尺度融合 (CTS Fusion)**
   - 時間尺度: [1, 3, 5]（可配置）
   - 融合類型: hierarchical_attention
   - 融合多時間框架特徵

5. **圖注意力層 (Graph Attention)**
   - 層數: 2（可配置）
   - 注意力頭數: 4（可配置）
   - Top-K 連接: 5（可配置）
   - 建模工具間關係

6. **輸出層**
   - 輸出維度: 256（可配置）
   - 池化方式: 平均池化（忽略填充）

### Quantum Enhanced SAC Agent

#### 架構組成

1. **策略網路 (Policy Network)**
   - 輸入: Transformer 特徵
   - 輸出: 動作分佈（每個工具的買/賣/持有）

2. **價值網路 (Value Networks)**
   - Q 網路: 兩個獨立的 Q 網路（用於雙 Q 學習）
   - V 網路: 狀態價值網路

3. **量子策略層 (Quantum Strategy Layer)**
   - 實現量子啟發的策略疊加
   - 支援多策略組合

4. **經驗回放緩衝區**
   - 大小: 每工具 5000 * 符號數量
   - 存儲: (state, action, reward, next_state, done)

### 訓練流程

1. **資料準備**
   - 從記憶體映射資料集讀取
   - 批次大小: 64（可配置）
   - 序列長度: 512（可配置）

2. **前向傳播**
   - 特徵提取 → Transformer → 策略網路 → 動作

3. **環境互動**
   - 執行動作 → 獲取獎勵 → 更新狀態

4. **反向傳播**
   - 計算 SAC 損失
   - 更新策略網路和價值網路
   - 使用自動混合精度（AMP）加速

5. **模型保存**
   - 每 N 步保存檢查點
   - 生成元數據檔案 (.meta.json)

## 風險管理系統

### RiskManager 功能

#### 風險參數

1. **暴露限制**
   - `max_total_exposure_usd`: 最大總暴露金額
   - `max_total_exposure_percent`: 最大總暴露百分比
   - `max_position_exposure_percent`: 單一工具最大暴露百分比

2. **倉位大小計算**
   - **ATR 模式** (`use_atr_sizing = true`):
     - 使用 ATR 計算止損距離
     - 根據風險金額和止損距離計算倉位
   - **固定點數模式** (`use_atr_sizing = false`):
     - 使用固定點數作為止損距離
     - 根據風險金額和點數計算倉位

3. **止損/止盈**
   - `stop_loss_atr_multiplier`: 止損 ATR 倍數（預設 2.0）
   - `take_profit_atr_multiplier`: 止盈 ATR 倍數（預設 3.0）
   - `stop_loss_pips`: 固定止損點數（預設 10）
   - `take_profit_pips`: 固定止盈點數（預設 10）

4. **回撤保護**
   - `hard_stop_loss_percent`: 硬止損百分比（從會話開始）
   - `trailing_stop_loss_percent`: 追蹤止損百分比（從峰值）
   - `daily_loss_limit_percent`: 每日虧損限制百分比

#### 風險評估流程

```
1. 檢查現有倉位
   ├── 避免同方向加倉（金字塔式加倉）
   └── 允許反向開倉（對沖）

2. 計算倉位大小
   ├── 根據風險百分比計算風險金額
   ├── 獲取工具詳細資訊（pip_location, minimum_trade_size）
   ├── 計算止損距離（ATR 或固定點數）
   ├── 計算每單位風險
   └── 計算交易單位

3. 應用暴露限制
   ├── 檢查總暴露限制
   ├── 檢查單一工具暴露限制
   └── 調整倉位大小（如需要）

4. 價格四捨五入
   ├── 根據工具精度四捨五入價格
   └── 根據最小交易單位調整單位

5. 返回交易詳情
   ├── units: 交易單位
   ├── stop_loss: 止損價格
   └── take_profit: 止盈價格
```

#### 風險監控

系統持續監控以下風險指標：

1. **會話開始權益**: 記錄會話開始時的帳戶權益
2. **峰值權益**: 追蹤會話期間的最高權益
3. **當前權益**: 實時帳戶權益
4. **回撤計算**:
   - 硬止損回撤 = (會話開始權益 - 當前權益) / 會話開始權益 * 100
   - 追蹤止損回撤 = (峰值權益 - 當前權益) / 峰值權益 * 100

當回撤超過設定閾值時，系統會觸發交易停止。
